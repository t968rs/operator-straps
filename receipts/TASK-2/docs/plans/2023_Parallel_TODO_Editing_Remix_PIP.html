D1 How does a split that finds the catalog lease held wait for it, once the lease moves to just before its dry run (catalog_lock waits 10 s by default)?

Chosen

  • D1A lease acquire --wait SECONDS in the driver; the split passes --wait 300 and reruns acquire up to 3 times in all on a held-lease refusal; the default stays 10 s

Unchosen

  • D1B No driver change; the agent prose loops on the 10 s acquire
  • D1C acquire waits until the 30-minute lease staleness

Developer choice 2026-11-17. The project rule puts settings a driver can act on in the driver, not in prose; 300 s plus the run fits one Bash call under its 600 s cap.

D2 Where do queued field updates live and what drains them?

Chosen

  • D2A The same todo-inbox folder and name scheme, files holding {"updates": [...]}; add --inbox drains adds and updates oldest first in one write; the todo-watch mod is unchanged

Unchosen

  • D2B A sibling update --inbox drain with its own folder or name prefix; the mod gains a second drain call

Developer choice 2026-11-17. One drain keeps one catalog write and one summary line; the mod drains by running add --inbox and passes its inbox: line through unparsed.

D3 Which item fields may a queued update set?

Chosen

  • D3A Exactly the fields an add spec may carry, less issue and url

Unchosen

  • D3B The D3A fields plus catalog_entry_ids

Developer choice 2026-11-17. The add spec list is already validated (types and the item schema); links, sources, issues, tracker and computed fields stay with the script.

D4 What skill surface comes with the driver changes?

Chosen

  • D4A todo-edit --split takes several ids and --update ID[, ID ...] -- <guidance> is new; either dispatches one todo-editor per id in one message; --update drains once

Unchosen

  • D4B Multi-id --split only; updates are queued by any agent with inbox put --update, documented only
  • D4C Driver and agent prose only

Developer choice 2026-11-17. Issue 309 acceptance dispatches three splits in one message; the update operation gives research findings a queued route into the catalog.
