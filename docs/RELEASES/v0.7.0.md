# v0.7.0 (proposed)

Since `v0.6.0`. Minor: harness and agent-watcher bumped their minor versions, and arc-straps is new.

## Plugins

| Plugin | Was | Now |
|---|---|---|
| harness | 0.55.1 | 0.65.1 |
| agent-watcher | 0.7.0 | 0.8.1 |
| arc-straps | (new) | 0.3.0 |

Unchanged: band-line, banner-status, bubble-stamp, git-status, parallel2-lanes, pytest-scope, session-bookmark,
todo-watch.

## Changes

- #251 Feature(arc-straps): `arc-help-pages` skill. It builds the help page a tool's "?"
  page links to from a fragment, a template and the canonical XML (`apply_help`, dry run first), and checks
  the page (`check_help_page`) and the tool's link targets (`check_links`). Its project paths come from the
  new `plugins.arc-straps.arc_help_pages` section
- #250 Feature(arc-meta): pass `<a href>` through to the "?" page and report `<para>` markup (`unsupported_para_markup`).
  An `<a>` without an `href` or text, nested in another `<a>` or left open is now `unparseable` and blocks apply
  for that field; a relative href breaks on the "?" page and is not checked
- #249 Fix(plan): sweeps skip the plan's own source document, so a spec committed on the plan's branch no longer
  blocks the freeze
- #248 Feature(todo): stable `todo-xxxx` item ids (issue #243). Retire, split, add and refresh move ranks and never
  rename an item; retired and split ids are recorded in `retired_ids` and `split_ids` and never drawn again,
  and the reference list names only the retired or split ids. `todo_sync.py migrate-ids` switches a catalog
  once, keeps the `legacy_ids` map and finishes a partial run through it on a rerun; add-todo, sync-gh-todo and
  the TODO operations refuse a catalog that has not switched. Update every install that runs `todo_sync` on a
  project, and that project's own `RepoToDo.schema.json`, before running `migrate-ids` there. Commit messages
  put `TODO` terms in backticks (`commit_format.md`).
- #247 Feature(harness): `auto_title` config key, the project-wide default for `--auto-title` in merge-commit-msg
  and pr-sum, with `--no-auto-title` to turn it off for one capture
- #244 Feature(harness): `--auto-title` for merge-commit-msg and pr-sum,
  which sets a compliant PR title through `gh pr edit` (issue #242)
- #240 Feature(harness): pr-sum comparison flows, the vertical alignment pass in `build`, a skill README and
  level 1 to 3 examples
- #239 Feature(harness): `DiffDelta` source-only line counts
- #237 Fix(harness): `pydantic` 2.1 floor
- #235 Feature(todo): add the add-todo skill to draft TODO items and file issues
- #229 Feature(plan): sealed item records with tree provenance, `record --staged`, `plan.py verify`
- #228 Feature(merge-commit-msg): squash mode
- #227 Todo refresh
- #224 Fix(merge-commit-msg): ASCII subject separator, refuse unusable PR titles
- #223 Refactor(pr-review): `review_briefs` module and lens enums
- #220 Feat(arc-straps): `arc-meta` skill
- #219 agent-watcher follow-up 3
- #218 agent-watcher follow-up 2
- #217 Pylint CI badge in the README
