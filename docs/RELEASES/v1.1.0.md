# v1.1.0 (proposed)

Since `v1.0.0`. Minor: harness and session-bookmark bumped their minor versions, so the level proposed at the
start of the cycle stands. Each branch that bumps a plugin adds its row to the table and one line per change
below, tagged with its PR number.

## Plugins

| Plugin | Was | Now |
|---|---|---|
| harness | 0.82.1 | 0.83.0 |
| session-bookmark | 0.3.1 | 0.4.0 |

Unchanged: agent-watcher, arc-straps, band-line, banner-status, bubble-stamp, git-status, parallel2-lanes,
pytest-scope, todo-watch, working-refs. The `superpowers-lt` entry points at its own repository and is
versioned there.

## Changes

- Feat(add-todo, session-bookmark): optional session goal for an added TODO item (issue #282).
  `add-todo --hook retired|committed|developer` adds a `Hook:` line to the row; once the inbox drain lands the
  item, `add_todo.py hook --todo <id> --closed-by <C>` (`TodoHook` on `AddTodoRequest`) arms
  `<state_dir>/session-bookmark/hook.json`, and `add_todo.py hook --clear` removes it. The session-bookmark
  mod's new `session_hook.ts` runs `/goal <goal>` through `$.command.run` at the end of the next main-loop
  turn and stamps the switch `fired`, so the goal is set once; a refused `/goal` leaves the switch armed and
  shows one toast. `tests/mods/test_session_bookmark_hook_contract.py` pins the switch path, version and keys
  on both sides. Each closing is one the agent meets itself (`committed`: tests passed and a commit message
  drafted; `developer`: tests passed and a handoff reply), since `/goal` re-checks at every stop.
- Feat(add-bookmark): `--goal <condition>` arms a free-text session goal, `--goal-todo <id> <closing>` the goal
  of a catalog item, `--goal-clear` removes the switch (`add_note.py goal`, through
  `add_todo_api.write_goal_switch`); `--remove` takes several numbers from one listing, and `--edit` takes
  several `N <text>` groups.
