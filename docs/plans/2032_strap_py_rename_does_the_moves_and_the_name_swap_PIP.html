Decisions

D1 Who performs the moves a rename needs?

Chosen

  • python-moves rename runs git mv itself, cross-OS, with --dry-run printing the list

Unchosen

  • print-only rename prints a move list for the developer to run

Developer chose the catalog recommendation (todo-57az).

D2 What happens to the old name inside files?

Chosen

  • swap-parts-report-rest swap kebab, snake and title forms in the moved parts and cited test files; only report other tracked files

Unchosen

  • report-only report every hit, swap nothing

Developer chose the catalog recommendation (todo-57az).

D3 How does a spec renamed before this change finish its rename?

Chosen

  • from-flag rename <name> --from <old-name> runs the moves, swaps and node re-points without moving the spec or ledger

Unchosen

  • hand the developer moves the files and edits the nodes by hand

The spec's goal for spec-it's leftovers; node ids are locked to the api, so only the driver can move them.
